# SW2.5消耗品カウンター（ゆとシート対応・非公式）

ソード・ワールド2.5の「ゆとシート」のキャラクターデータから消耗品を読み込み、
セッション中の個数をボタンで管理して、補充に必要な金額を計算するWebページです。

- 公開ページ: https://Rast-Rabbit.github.io/sw2.5-consumable-counter/
- 使い方は、ページ内の「使い方」タブに書いてあります。

## できること
- ゆとシートのURLを貼るだけで、アイテム欄の `[消耗品]` の表とマテリアルカードを読み込む
- 「−」「＋」ボタンで個数を管理（数字のタップで直接入力もできる）
- 使用宣言の文章（`【魔晶石（５）】ＭＰを５点代用できる`）をワンタップでコピー
- 拾ったアイテム・マテリアルカードの追加
- 精算: 補充する物にチェックを入れ、合計金額を表示。ゆとシートに書き換える個数の一覧も出す
- 操作ログ（時刻つき）、自動保存、ファイルへの保存と読み込み

## 注意
- 本ツールは個人が作成した非公式のもので、[ゆとらいず工房](https://yutorize.work/)の公式サービスではありません。
- ゆとシートのデータは、公式に案内されているJSON形式での取得機能（`&mode=json`）を使って読み込んでいます。通信は読み込み時の1回だけです。
- 入力したデータは、お使いの端末の中にだけ保存されます。外部へは送信しません。
- 「ソード・ワールド」は、グループSNEおよびKADOKAWAの作品です。

## 開発メモ
- ビルド不要の HTML / CSS / JavaScript だけで動きます（`index.html` を配信するだけ）。
- テスト: `node --test tests/`（Node.js 18以上）
- `js/sheet.js`: URL・取得・解析、`js/model.js`: 状態と計算、`js/app.js`: 画面
